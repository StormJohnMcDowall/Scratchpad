# Backups Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep dated copies of the note in `%LOCALAPPDATA%\Scratchpad\backups\`:
- hourly while editing;
- on exit;
- straight away before any big delete.

Copies are pruned to 48 hours plus one per day for 30 days, and Settings can open the folder.

**Architecture:**
- **Core (unit-tested):**
  - `BackupRules`: the removed-characters measure, the big-delete rule, file naming and parsing, the hourly decision and the pruning decision. Everything is pure, with "now" passed in.
  - `BackupStore`: writes copies and prunes the folder, best-effort and thread-safe.
- **Shell:** `MainWindow` hooks the store into:
  - the autosave callback, for hourly copies;
  - `TextChanged`, for before-big-delete copies;
  - `App.OnExit`, for the exit copy.

  Settings gets a Backups section.

**Tech Stack:** WPF on .NET Framework 4.8, netstandard2.0 Core, xUnit.

**Spec:** `docs/superpowers/specs/2026-11-04-backups-design.md`. Read it first. Its anti-goals bind every task.

## Global Constraints

- No new NuGet dependencies.
- Folder: `%LOCALAPPDATA%\Scratchpad\backups\`.
- File names, in local time:
  - regular copies: `scratchpad yyyy-MM-dd HHmmss.md`;
  - before-big-delete copies: `scratchpad yyyy-MM-dd HHmmss before big delete.md`.
- Big delete: removed ≥ 1000 characters, or (before.Length ≥ 100 and removed ≥ half of before.Length).
- Hourly: at most one regular copy per hour, measured from the newest **regular** copy, and only when the text differs from that copy.
- Pruning:
  - keep everything with time ≥ now − 48 h;
  - delete anything dated before `now.Date.AddDays(-30)`;
  - between those, keep only the newest copy (of either kind) per local calendar day.
  - Never delete a file whose name doesn't parse.
- Text is written as UTF-8 without BOM, matching `File.WriteAllText`'s default in `DocumentStore`.
- Every backup operation swallows its exceptions. It must never throw into the autosave, `TextChanged` or exit.
- Exact copy in Settings:
  - group header `Backups`;
  - line `Copies of the note from the last 30 days.`;
  - button `Open backups folder`.
- Build/test: `dotnet test Scratchpad.Core.Tests`; `dotnet build Scratchpad/Scratchpad.csproj`.

## Review Focus

1. **The window is never opened, then the user exits from the tray.** `EditorTextBox.Text` is still `""`, so the exit copy must not write an empty "backup" that differs from the newest copy. Only write it once the note has been loaded (Task 3 guard).
2. **Loading the note.** `Window_Loaded` sets `EditorTextBox.Text` from `""`, which is not a delete and has no "previous text" yet. It must not create a before-big-delete copy, and the previous-text tracker must start from the loaded text (Task 3).
3. **Two big deletes in the same second.** Select all, Delete, then Ctrl+Z and Delete again quickly. The first copy holds the real old note and must not be overwritten by the second. `TryWriteBeforeBigDelete` never overwrites an existing file (Task 2 test).
4. **The backups folder holds the user's own files,** e.g. `notes.txt` or `scratchpad old.md`. Pruning must leave them alone (Task 1 test).
5. **Concurrent writers.** Hourly copies run on the autosave's thread-pool thread, while before-big-delete and exit copies run on the UI thread. The store's in-memory "newest regular copy" must stay consistent; guard it with a lock (Task 2).

### Task 1: BackupRules

**Files:**
- Create: `Scratchpad.Core/BackupRules.cs`
- Test: `Scratchpad.Core.Tests/BackupRulesTests.cs`

**Interfaces:**
- Produces:
  - `public enum BackupKind { Regular, BeforeBigDelete }`
  - `public static class BackupRules`, with:
    - `int RemovedLength(string before, string after)`:
      - Take the common prefix length `p`.
      - Take the common suffix length `s`, capped so it never overlaps the prefix in either string (`s ≤ min(before.Length, after.Length) − p`).
      - Return `before.Length − p − s`.
    - `bool IsBigDelete(string before, string after)`: the Global Constraints rule.
    - `bool IsHourlyCopyDue(DateTime? newestRegular, DateTime now)`: true when the argument is null or `now − newestRegular ≥ 1 hour`.
    - `string FileName(DateTime time, BackupKind kind)`, using the Global Constraints names with `CultureInfo.InvariantCulture`.
    - `bool TryParseFileName(string fileName, out DateTime time, out BackupKind kind)`: an exact match of either pattern, otherwise false.
    - `IReadOnlyList<string> FilesToDelete(IEnumerable<string> fileNames, DateTime now)`:
      - the names (not paths) to delete under the pruning rule;
      - names that don't parse are never included;
      - for "newest per day", ties keep one.

### Task 2: BackupStore

**Files:**
- Create: `Scratchpad.Core/BackupStore.cs`
- Test: `Scratchpad.Core.Tests/BackupStoreTests.cs`

**Interfaces:**
- Consumes: `BackupRules` and `BackupKind` (Task 1).
- Produces: `public class BackupStore`, with:
  - `static string DefaultFolder` (`%LOCALAPPDATA%\Scratchpad\backups`)
  - `BackupStore(string folder)` and `string Folder`
  - `bool TryWriteRegularIfDue(string text, DateTime now)`: writes when `IsHourlyCopyDue(newestRegular, now)` and the text differs from the newest regular copy's text.
  - `bool TryWriteOnExit(string text, DateTime now)`: writes when the text differs from the newest regular copy's text, ignoring the hour.
  - `bool TryWriteBeforeBigDelete(string oldText, DateTime now)`: always writes, but never overwrites an existing file. If the name is taken, it returns false.
  - Every method returns true only if a file was written. Each one:
    - creates the folder if needed;
    - prunes with `FilesToDelete` after writing;
    - catches every exception and returns false.
  - The newest regular copy's time and text are found lazily from disk on first use (the newest parsable Regular file), then kept in memory as copies are written. All state sits behind one `lock`.

### Task 3: Hook backups into the note and Settings

**Files:**
- Modify: `Scratchpad/MainWindow.xaml.cs`, `Scratchpad/App.xaml.cs`, `Scratchpad/SettingsWindow.xaml`, `Scratchpad/SettingsWindow.xaml.cs`

**Interfaces:**
- Consumes: `BackupStore` and `BackupRules.IsBigDelete` (Tasks 1–2).
- Produces:
  - `MainWindow.WriteExitBackup()` (public), called from `App.OnExit`.
  - `SettingsWindow.OpenBackupsFolderRequested` (`event Action`).

- [ ] **Step 1: Hourly copies.**
  - Add the field `private readonly BackupStore _backupStore = new BackupStore(BackupStore.DefaultFolder);`.
  - Change the autosave construction to save with `content => { _documentStore.Save(content); _backupStore.TryWriteRegularIfDue(content, DateTime.Now); }`.
  - The note's own save runs first, so a backup can never delay or block it.
- [ ] **Step 2: Before-big-delete copies.**
  - Add `private string _previousText;` (null until the note is loaded).
  - In `Window_Loaded`, set `_previousText = null` before assigning `EditorTextBox.Text`.
  - In `EditorTextBox_TextChanged`, before `NotifyChanged`:
    - read `var text = EditorTextBox.Text;`;
    - if `_previousText != null && BackupRules.IsBigDelete(_previousText, text)`, call `_backupStore.TryWriteBeforeBigDelete(_previousText, DateTime.Now)`;
    - then `_previousText = text;`.
  - Loading therefore only records the text (Review Focus 2).
  - Comment why this runs here: the autosave fires 500 ms later, when the old text is gone.
- [ ] **Step 3: Exit copy.**
  - `public void WriteExitBackup()` calls `_backupStore.TryWriteOnExit(EditorTextBox.Text, DateTime.Now)` only when `_previousText != null`, meaning the note was loaded this session (Review Focus 1).
  - In `App`, keep the main window in a field and override `OnExit(ExitEventArgs e)` to call `_mainWindow?.WriteExitBackup()` (wrapped in try/catch) before `base.OnExit(e)`. `Exit` runs both for the tray's Exit and for Windows ending the session.
- [ ] **Step 4: Settings.**
  - In `SettingsWindow.xaml`, add an eighth `RowDefinition`.
  - Insert `GroupBox Grid.Row="6" Header="Backups" Margin="8,0,8,8"` after Fonts. Fonts' bottom margin is already 8, so this one has none on top.
  - Move Reset to `Grid.Row="7"`.
  - Inside the group: a `StackPanel Margin="8"` with `TextBlock Text="Copies of the note from the last 30 days." TextWrapping="Wrap"` and `Button x:Name="OpenBackupsFolderButton" Content="Open backups folder" HorizontalAlignment="Left" Padding="8,4" Margin="0,6,0,0" Click="OpenBackupsFolderButton_Click"`. The click raises `OpenBackupsFolderRequested`.
  - In `MainWindow.OpenSettings`, subscribe a handler that, inside try/catch:
    - runs `Directory.CreateDirectory(BackupStore.DefaultFolder)`;
    - then runs `Process.Start("explorer.exe", "\"" + BackupStore.DefaultFolder + "\"")`.
- [ ] **Step 5: Build and test.** Run `dotnet build Scratchpad/Scratchpad.csproj` and `dotnet test Scratchpad.Core.Tests`. Expected: 0 errors, and all tests pass.
